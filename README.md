Simple AI Chatbot is an AI-based conversational project created using n8n and an AI API key. The purpose of the project is to build a chatbot that can receive a user's question, send it to an AI model through an API, process the response, and return the AI-generated answer to the user.

The project demonstrates how n8n's node-based workflow automation can be used to connect a user interface with an AI service without requiring a large amount of backend programming.

**Project Objective**

**The main objective is**
To create a simple AI chatbot using n8n that accepts user questions, sends them to an AI model through an API key, receives the generated response, and displays the answer to the user.

**The chatbot can be used for**:

General question answering
Educational assistance
Customer support
Information retrieval
Basic personal assistance
FAQ automation
**Technologies Used**
n8n

n8n is used to create and manage the chatbot workflow through connected nodes.

AI API

An AI provider's API is used to communicate with the AI model. The API key authenticates the application with the provider.

AI Model

The AI model receives the user's question and generates a natural-language response.

Chat Interface

The user can interact with the chatbot through an n8n chat interface, webhook-based interface, or another frontend connected to the workflow.

**Conclusion**

The Simple AI Chatbot using n8n and API Keys is a beginner-friendly project that demonstrates how a conversational AI application can be built using visual workflow automation.
